# Display & Audio Control

Resolution, brightness, arrangement, audio devices, mic mute and AirPods modes.

> **Status:** planned — not yet functional. See [PLAN.md](PLAN.md).

## Usage

Resolution, brightness, arrangement, audio devices, mic mute and AirPods modes via the `res` keyword.

![Display & Audio Control results in Alfred](images/res.png)

* <kbd>↩</kbd> Primary action.
* <kbd>⌘</kbd><kbd>↩</kbd> Secondary action.
* <kbd>⌘</kbd><kbd>Y</kbd> Quick Look.

Every keyword can be changed in the Workflow’s Configuration.

## Development

```bash
./build.sh   # -> dist/alfred-display-audio-<version>.alfredworkflow
```
